# NOTES — рабочие заметки

Живой файл: сюда пишем решения, найденные подводные камни и следующие шаги.

## 2026-11-22 — 0.16.0: «Общие дела» и надёжность

- Новый модуль `core.tasks` — «Общие дела»: общий список для пары, отметка выполнения,
  необязательный срок и заметка, редактирование и мягкое удаление. Модуль включается в магазине
  дополнений и работает без сети.
- Данные — Room v12 (миграция 11→12), UUID/tombstone/LWW; задачи входят в общий sync, серверный
  API и ручной backup. Старые backup без `tasks` импортируются с пустым списком.
- Надёжность: лента расписания обновляется после полуночи и при возврате в foreground; устранена
  гонка «выбрать дату → добавить урок»; дни рождения из профиля не дублируются ручными ежегодными
  событиями.
- Проверка: Android `testDebugUnitTest`, debug/release, server `test`.
- Релиз: 0.16.0, versionCode 28.

## 2026-11-22 — техдолг после 0.15.0

- «Расписание» обновляет «сегодня» в полночь и при возврате в foreground; выбранная
  пользователем дата при этом не сбрасывается. Лента дат больше не фиксирует `LocalDate.now()`
  в `remember` на всё время жизни экрана.
- Быстрый тап «другая дата → добавить» больше не открывает черновик на старом дне недели:
  `addLesson` читает выбранную дату напрямую из `StateFlow`, а не из асинхронного UI-state.
- Дни рождения из профиля пары дедуплицируются с ручными **ежегодными** событиями по месяцу
  и дню в календаре, счётчике «Главной» и виджете. Разовые и удалённые события ничего не скрывают;
  29 февраля сравнивается как обычный месяц/день.
- README и ROADMAP приведены к фактическому состоянию 0.15.0; FCM, музыка, Steam и будущие
  модули остаются неотмеченными.
- Проверка: Android `testDebugUnitTest`, `assembleDebug`, `assembleRelease`; добавлены unit-тесты
  на гонку выбора даты, смену дня и дедупликацию дней рождения. Инфраструктуры для JVM-теста
  Room-миграции 10→11 в проекте нет — миграция остаётся проверенной на устройстве.

## 2026-11-22 — 0.15.0: кнопка «Сегодня» на карточке пары

- На карточке пары — круглая кнопка «Сегодня»: цифра — сколько уроков на сегодня, точка — есть
  событие календаря в пределах срока напоминаний, без значков — на сегодня ничего. Дни рождения
  точку не зажигают — только настоящие события.
- Шторка «Сегодня»: дата с днём недели, уроки (время, предмет, кабинет, кто берёт учебник) и
  ближайшие события с подписями «сегодня / завтра / через N дней» (плюралы ru/en). Дни рождения
  пары идут в том же списке с сердечком — как в календаре, чтобы экраны не расходились.
- Срок показа — `leadDays` из настроек напоминаний календаря (1 / 3 / 7 дней, по умолчанию 7),
  отдельной настройки нет. Уроки — по дню недели из `LessonRepository`, без удалённых, сортировка
  по `startMinute`; при выключенном «Расписании» блок уроков скрыт.
- Добавлены `Dates.formatWeekday` и токены `VdvoemSizes.roundButton/dot/timeColumn`; строки — в
  `values` и `values-en`. Значок рисуется отдельным слоем поверх кнопки: внутри `IconButton` его
  обрезает круглый клип.
- Проверка: SM-A546E (Android 16), светлая/тёмная тема, поворот, перезапуск процесса; состояния
  «уроки + точка», «только точка», «пусто»; `FATAL`/`ANR` нет.
- Релиз: 0.15.0, versionCode 27.

## 2026-11-17 — аудит синхронизации, приватности и стабильности

- Три независимых аудита нашли критические проблемы: утечку записей старой пары, потерю офлайн-правок
  из-за timestamp-watermark и часов, IDOR на сервере, потерю tombstones, раскрытие сюрпризов через sync/backup.
- Sync переведён на серверные монотонные `revision`/cursor и per-record acknowledgements в DataStore;
  outgoing фильтруется по текущему `pairId`, pairing сериализован с sync. На сервере owner-check во всех upsert,
  отзыв устройства при leave, лимиты sync/WS, device-binding для приватных сюрпризов.
- Исправлены удаления events/lessons/cycle, LWW tombstones, атомарный и LWW-aware backup, приватность wishes/gifts,
  даты покупки подарков, атомарное wish→gift. Room обновлён до v10: v9 — приватность/даты подарков,
  v10 — date-only в UTC без сдвига при смене часового пояса.
- Исправлены yearly/background reminders, FGS timeout, запуск push после pairing, обновление виджета,
  ввод веса, прогноз цикла, all-day export, рекорды тестов, микрофон/плеер, счётчики, редакторы и доступность.
- Release APK запрещает cleartext и публикуется из `assembleRelease`; updater выбирает только `*-release.apk`.
  На srv1 развёрнут Caddy с доверенным сертификатом: `https://185.213.240.43.sslip.io:18443` (HTTP/WS
  проксируются на прежний API; порт 443/xray не затронут). Старый HTTP `:18090` оставлен для старых APK.
  Сервер одновременно отдаёт legacy flat sync и новый envelope; старый URL автоматически мигрирует на HTTPS.
- Проверка: Android `testDebugUnitTest`, `assembleDebug`, `assembleRelease`; server `test build`.
  Production smoke по HTTP и HTTPS: создание пары, legacy/new sync, push и revoke — успешно.
  Перед миграцией сделан `pg_dump` в `/opt/vdvoem/backups`; тестовые пары удалены.
  На устройстве после этого пакета ещё нужны migration/sync smoke-test и скриншоты; у server пока нет unit-тестов.

## Решения

| Дата | Решение | Почему |
|---|---|---|
| 2026-11-14 | Название «Вдвоём», кодовое Tandem | нравятся оба, тёплое и международное |
| 2026-11-14 | Material 3 без Expressive | стабильные компоненты, меньше риска при обновлениях |
| 2026-11-14 | Синк пары — критичная функция, не «потом»; сейчас нет хостинга → sync-ready модель + ручной обмен | ключевая ценность приложения для пары |
| 2026-11-14 | Local-first | быстрый MVP без серверной инфраструктуры |
| 2026-11-14 | Модули внутри одного APK | проще, чем dynamic feature/внешние APK |
| 2026-11-14 | Музыка — свой сервер (стрим/скачивание) | у Spotify/Яндекс.Музыки нет открытых API |
| 2026-11-14 | Steam — полный клиент, но отдельным модулем позже | неофициальные API, риск для аккаунта |
| 2026-11-14 | Токены + обёртки компонентов | смена дизайна по референсам должна быть дешёвой |
